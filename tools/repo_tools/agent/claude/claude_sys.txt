# PTStudio Agent Environment

## Bash Tool Usage

1. **Always use `./pts` entrypoint** - The Bash tool runs in bash, so use `./pts` (not `.\pts.cmd`).
2. **All repository operations go through `./pts`**: `build`, `test`, `format`, `clean`, `python`. Use `./pts -h` or `./pts <cmd> -h` for options. Do not attempt to infer the build system/ test driver executable and environment.

## Project Overview

**PTStudio**: C++17 3D editor/renderer using WebGPU (Dawn native, emdawnwebgpu for WASM), OpenUSD, plugin system.

## Structure

- **core/**: Static lib - windowing, WebGPU (`WebGpuContext`, `Device`, `Surface`), render graph, plugin system, ImGui
- **editor/**: Main executable - ImGui-based editor UI, hosts renderer plugins
- **plugins/**: Dynamic (static on WASM) - `renderers/editor/`, `test_plugin/`
- **hello_triangle/**: Simple WebGPU example

**Build output**: `_build/<config>/bin/` (executables), `_build/<config>/bin/plugins/` (plugins)
